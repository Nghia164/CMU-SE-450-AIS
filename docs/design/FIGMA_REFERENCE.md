## Required agent behavior

1. Open the Figma file and inspect the relevant pages and frames before creating or redesigning a screen.
2. Match the approved frame's layout, navigation, typography, colors, spacing, table density, forms, buttons, and modal behavior.
3. Reuse the existing React components where they match the design. Extend them consistently where necessary.
4. Do not treat Figma as the authority for business rules or role permissions; verify those in the approved SRS.
5. If a required screen is missing from Figma, report the gap instead of pretending that a reference exists.
6. If the coding agent cannot access Figma directly, ask the user to export relevant frames as PDF/PNG and save them under `docs/design/figma-exports/`. Do not claim to have inspected a live Figma file without access.
